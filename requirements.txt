# AI DOCUMENT PROCESSING INSTALLATION INSTRUCTIONS:
# Uses only Python libraries - no third-party API keys required
#
# 1. Install Python dependencies:
#    pip install pytesseract PyPDF2 python-docx pyresparser spacy nltk
#
# 2. Install Tesseract OCR (for better image OCR):
#
#    WINDOWS:
#    - Download from: https://github.com/UB-Mannheim/tesseract/wiki
#    - Install the executable
#    - Add Tesseract to your PATH environment variable
#
#    LINUX (Ubuntu/Debian):
#    sudo apt-get update
#    sudo apt-get install tesseract-ocr
#
#    macOS:
#    brew install tesseract
#
# 3. Install spaCy and NLTK models (for pyresparser):
#    python -m spacy download en_core_web_sm
#    python -m nltk.downloader words
#
# 4. Test installation:
#    python test_simple_ocr.py
#
# 5. Text Extraction Methods (in order of preference):
#    - pyresparser (for resumes - most accurate)
#    - Local Tesseract OCR (for images)
#    - PyPDF2 PDF text extraction (for PDFs)
#    - python-docx text extraction (for DOCX files)
#    - Basic text file reading (for TXT files)


# FACE RECOGNITION INSTALLATION (after pip install -r requirements.txt):
#
# --- WINDOWS (use pre-built dlib wheel; do NOT let pip build dlib from source) ---
#
# Option A - Run the helper script (recommended):
#   .\scripts\install_face_recognition_windows.ps1
#
# Option B - Manual (install dlib from wheel FIRST, then face_recognition):
#   1. Check Python: python --version  (e.g. 3.11)
#   2. Install dlib from a pre-built wheel (pick one that matches your version):
#      pip install https://github.com/Murtaza-Saeed/Dlib-Precompiled-Wheels-for-Python-on-Windows-x64-Easy-Installation/raw/master/dlib-19.24.1-cp311-cp311-win_amd64.whl
#      (for 3.10 use cp310, for 3.12 use cp312 in the filename)
#   3. pip install face_recognition
#
# Option C - Conda: conda install -c conda-forge dlib && pip install face_recognition
#
# --- LINUX / MAC ---
#   pip install cmake && pip install dlib && pip install face_recognition
#
# TROUBLESHOOTING:
# - Never run "pip install face_recognition" alone on Windows first; that pulls dlib and tries to build it. Always install a dlib wheel first, then face_recognition.
# - If the script says "No pre-built wheel", download a .whl from the Murtaza-Saeed repo and: pip install path\to\dlib-....whl then pip install face_recognition
